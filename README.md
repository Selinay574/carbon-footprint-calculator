# Carbon Footprint Calculator

## Project Overview
This project is a web-based Carbon Footprint Calculator developed using Python and Django. It allows users to calculate their carbon footprint based on their energy consumption and vehicle fuel usage.

## Features
- Calculate carbon emissions from electricity consumption (kWh).
- Calculate carbon emissions from natural gas consumption (m³).
- Select vehicle fuel type (Gasoline, Diesel, LPG).
- Enter fuel consumption in liters.
- Display calculated carbon footprint results.

## Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite

## Project Purpose
The aim of this project is to help users understand the environmental impact of their energy consumption and vehicle fuel usage and raise awareness about carbon emissions.

## Project Structure
- `karbon/`: Main Django application
- `proje/`: Django project settings and configuration
- `static/`: CSS, JavaScript and image files
- `manage.py`: Django management script
